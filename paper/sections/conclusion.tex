\section{Conclusion}
\label{sec:conclusion}

Lineage has been treated as documentation: drawn, displayed and trusted. Konstruct treats it as
a claim. It derives lineage, formulas and an ontology from the code a team already has, joins them
across the tools the team already uses, and then checks the lineage against the data, reporting
what the data confirms, what it does not exercise and what the graph does not explain, each
observation reproducible from the recorded seed. The result is a set of facts about a data stack
that a person can trace and an agent can be grounded in, produced locally, under the MIT licence,
by a tool that is itself open. The measurements of Konstruct in this paper are not a snapshot:
they are regenerated from the code with every change, so the paper can be checked the same way
the lineage can.
